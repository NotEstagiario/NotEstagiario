## Projeto em destaque

### Eteryun MMO
**Software Developer / Game Developer · Projeto autoral · Em desenvolvimento**

- Arquitetura **server-authoritative** com componentes cliente-servidor.
- Persistência em **MySQL/MariaDB**, validação no servidor e transações.
- Separação entre estado persistente e transitório.
- Sistemas de RPG e gameplay: identidade de personagem, atributos, progressão, combate, loot, economia e balanceamento.
- Testes, depuração, QA técnico e manutenção evolutiva.

> O repositório principal é privado durante o desenvolvimento.
